DFCNet: Global Degradation-Aware Dynamic Frequency Collaboration for Image Dehazing
This repository provides the official implementation of DFCNet, a global degradation-aware dynamic frequency collaboration framework for image dehazing.
📖 Overview
DFCNet aims to address the limitations of existing image dehazing methods in adapting to image-specific degradations and effectively coordinating information across frequency components.
By integrating global degradation perception, dynamic feature modulation, and cross-frequency collaboration within a hierarchical wavelet-based framework, DFCNet enables adaptive restoration of degraded images while preserving structural information and fine-grained details.
The framework consists of three main components:
Global degradation-aware modeling to capture image-specific degradation characteristics and provide adaptive restoration guidance.
Dynamic frequency collaboration to facilitate complementary interactions between low- and high-frequency features.
Hierarchical restoration and detail enhancement to progressively recover image structures and refine visual details.
Extensive experiments on synthetic and real-world dehazing benchmarks demonstrate the effectiveness of DFCNet.
